# Changelog

## v0.1.0

### Added

* Alternate task statuses with Minimal-style icons and theme-aware colors.
* Click-to-uncheck behavior for custom statuses.
* Desktop context-menu and touch long-press status picker.
* Command-palette access to the status picker.
* Localized English and Simplified Chinese labels.
* Settings for controlling which statuses appear in the picker.
* Optimistic native API persistence with rollback on failure.

### Removed

* The inherited sample plugin UI and kernel demo.
* Direct sample tabs, docks, dialogs, and unrelated commands.
